# Clicbiota

Prototipo web educativo para explorar registros de flora y fauna de países y territorios mediante un globo interactivo.

**Sitio público:** https://clicbiota.peacefulrhino3.chatgpt.site

## Cómo usarlo

- En línea: abre el [sitio público](https://clicbiota.peacefulrhino3.chatgpt.site).
- En Windows: ejecuta `01_producto_digital/abrir_prototipo.bat`. Se requiere Python 3 e internet para cargar el globo, los límites geográficos y Nunito.
- Los datos del prototipo están incluidos como archivos JSON en `01_producto_digital/app/data/`.

## Entrega del proyecto

- `01_producto_digital/app/`: interfaz web, estilos, código y datos de 250 países y territorios.
- `02_registro_de_recursos.csv`: fuentes, licencias o condiciones y créditos. La versión HTML está junto al CSV.
- `03_analisis_etico.md`: caso, alternativas, decisión y límites.
- `04_codigo_de_conducta.md`: tres compromisos del equipo.
- `05_presentacion.html` y `06_guion_de_exposicion.md`: ocho diapositivas y exposición de nueve minutos.

## Alcance de los datos

Las fichas muestran hasta ocho taxones de fauna y flora por lugar, ordenados por registros georreferenciados publicados en GBIF. Los recuentos reflejan registros disponibles; no representan abundancia real ni prueban que una especie sea nativa. Revisa el análisis ético y el registro de recursos antes de reutilizar la información.
